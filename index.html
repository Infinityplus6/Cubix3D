Cubix 3D Controls & Shortcuts

You can interact with the cube using your mouse or keyboard shortcuts:

Keyboard Controls (Singmaster / Speedcubing)

Rotate Right (R / R')I / K
Rotate Left (L / L')D / E
Rotate Up (U / U')J / F
Rotate Down (D / D')S / L
Rotate Front (F / F')H / G
Rotate Back (B / B')W / O
Middle Slice (M / M')M / N
Rotate Whole X (X / X')X / Shift+X
Rotate Whole Y (Y / Y')Y / Shift+Y

Notation Guide

N = 90° Clockwise rotation

N' = 90° Counter-Clockwise (Inverse) rotation

N2 = 180° Double rotation

M, E, S = Middle slice rotations

X, Y, Z = Rotate entire cube around X, Y, or Z axis
